What it does today

Think of it as a knowledgeable colleague who has read every Confluence page and Jira ticket — and gives you a structured answer in under a minute.

  • Submit a Jira ticket ID, describe a client requirement, or upload a document (PDF, images, text)
  • The agent searches Jira, Confluence, Capillary product docs, and docs.capillarytech.com for real precedents
  • Returns a structured assessment: Problem → Verdict → Approach → Complexity → References → Open Questions
  • Can generate full documents: BRDs, SDDs, Gap Analyses, Architecture Diagrams
  • When a request is too complex, it flags for SA escalation with a pre-filled summary

Specialist skills

The agent activates specialist capabilities depending on what you ask — like calling in a subject matter expert.

🎯 CR Evaluator

Feasibility rubric for CR, BRD, and issue requests. Knows what's OOTB, what needs configuration, and what requires custom development in Capillary.

📋 PM Pipeline / BRD Writer

Full 3-phase delivery: BRD Creation (question sets A-F, 21 sections) → Discovery Dashboard (prefilled, guardrails) → Jira Ticket Generation. Includes BRD evaluation & scoring.

📄 SDD Writer

Generates Solution Design Documents with parallel research and section-by-section writing. Full SDD for new integrations, Lite SDD for CRs.

📊 Gap Analyzer

Compares a BRD against Capillary capabilities. Scores each domain, identifies gaps, and suggests resolution paths with verified API evidence.

🖼️ Diagram Generator

Creates visual architecture diagrams as Excalidraw JSON for solution architecture, workflows, and system flow visualisation.

Adding a new skill means creating a folder with instructions — no code changes needed. Skills declare their own execution mode, research needs, and validation rules.

BRD Pipeline — deep dive

The newest skill: a complete PM pipeline from requirements gathering to Jira backlog creation.

📝
Phase 1: BRD Creation — Guided question sets (A-F) covering scope, modules, integrations, timelines. Generates a 21-section BRD with member journey flows. Auto-runs evaluation with guardrail checks (G1-G6).
🔍
Phase 2: Discovery Dashboard — Prefilled from signed BRD. Yes/No quick-confirm section, live guardrail status panel, clarification register. Must reach 100% completion to proceed.
🎫
Phase 3: Jira Tickets — Generates Epics (one per module) → Stories (one per FR) → Acceptance Criteria. All fields populated dynamically from the signed BRD.
📊
BRD Evaluation Mode — Upload an existing BRD and get it scored: 12-section completeness check, 6 guardrail categories, key gaps report with IDs/owners/due dates, and top improvement rewrites.

Gate system: Gate 1 requires zero critical gaps + all sections ≥ 3/5 + client BPO sign-off. Gate 2 requires 100% discovery + all guardrail items resolved. No shortcuts.

Engineering optimizations

Under the hood, several optimizations keep the agent fast and cost-efficient.

⚡
Parallel pre-flight — Classification and skill detection run simultaneously, saving 300-500ms per request.
🔀
Parallel research agents — Domain-specific Haiku sub-agents research Jira, Confluence, and docs simultaneously. 3-5× faster, 60-70% cheaper.
🗜️
Context compaction — Long conversations auto-summarised to keep the context window lean. Full history preserved in DB.
🚪
Off-topic gate — Fast Haiku classifier intercepts irrelevant requests before they reach the main loop.
💰
Model dispatch policy — Every operation routed to the cheapest model that can handle it.
📋
Agent planning — Auto-creates structured plans for complex tasks with real-time progress tracking.

Future Path — Neo & Codebase Intelligence

Evolving from a documentation assistant into a full solution intelligence layer with code-level understanding.

🧠 Neo Integration — Guide Users to the Best Solution

Deep integration with Capillary Neo (Extension 2.0) — the low-code platform for custom dataflows. Instead of just saying "this needs a custom extension," the agent will:

→ Show exactly which Neo dataflow template to use
→ Identify where an issue is coming from in existing Neo configuration
→ Suggest the optimal path (OOTB config vs. Neo workflow vs. Classic extension)
→ Generate Neo dataflow JSON scaffolds for common patterns

💻 Full Codebase Access

The agent will gain access to Capillary's entire codebase — enabling it to:

→ Trace issues to their root cause in source code
→ Identify which service/module handles a specific feature
→ Show SAs exactly where to look when debugging client issues
→ Generate accurate effort estimates based on actual code complexity
→ Suggest code-level solutions with file paths and function references
